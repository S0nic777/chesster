# Chesster ♟️

Chesster is a high-performance, real-time matchmaking and competition management platform built with **Flutter** and powered by **Supabase**. It features sophisticated Elo-based matchmaking, anti-cheat monitoring, and dynamic tie-breaking systems.

## ✨ Features

- **Global Matchmaking:** Intelligent Elo-range expansion for fast and fair matches.
- **Competition Management:** Tiered competition structures and real-time scoring.
- **Anti-Cheat Observer:** Built-in heuristics to monitor and ensure fair play.
- **Modern UI:** A sleek, dark-themed interface built with Flutter's latest standards.
- **Supabase Integration:** Seamless real-time database and authentication.

## 🚀 Getting Started

1. Clone the repository: `git clone https://github.com/S0nic777/chesster.git`
2. Install dependencies: `flutter pub get`
3. Configure Supabase keys in `lib/main.dart`.
4. Run the app: `flutter run`
